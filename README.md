## О проекте

Учебный проект по предмету "Основы объектно-ориентированного программирования".  Работаем над поэтапным созданием бота: от эхо бота, до полноценного кроссплатформенного бота с базой данных, многопоточностью и не только.
  
---  

## ✨ Возможности

- ✅ Отслеживать настроение
- ✅ Просматривать историю отметок
- 🔒 Безопасность обеспечивает telegram.


  
---
## Использование

Доступные команды:
* `/start`
* `/help`
* `/checkin`
* `/history`
